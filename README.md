# Gestion Magasin AORTech

Application Web Java Enterprise Edition (JEE) pour la gestion d'un magasin high-tech digital.

## Fonctionnalités principales

- **Espace Client**:
  - Barre de navigation unifiée avec icônes Profil et Panier.
  - Offres spéciales et promotions.
  - Section Marques avec filtre dynamique par marque.
  - Catalogue complet et recherche.
  - Reçus et historique des commandes.
  - Devise en MAD.

- **Espace Administration**:
  - Tableau de bord analytique.
  - Gestion des produits, catégories, fournisseurs, clients et ventes.

## Démarrage

`bash
mvn clean compile
`
